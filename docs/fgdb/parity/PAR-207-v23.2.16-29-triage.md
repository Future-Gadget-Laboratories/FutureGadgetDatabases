# PAR-207: CockroachDB v23.2.16–v23.2.29 public fix-note triage

This is FGL work based only on public CockroachDB v23.2 patch release notes. The tree pin is v23.2.15 `cockroach-oss`. Each row records source-note triage and a code-surface check; no reproduction was possible, so every confirmation remains pending. Source attribution for all notes: **CockroachDB v23.2.x release notes**.

Classifications describe the v23.2.15 OSS tree: `present-in-OSS` means a relevant OSS subsystem exists, not that the defect was reproduced; `CCL-only` means the named feature is Enterprise and excluded from `cockroach-oss`; `not-present` means the described setting, API, regression, or licensing surface is later than the pin; `needs-repro-to-decide` means relevant OSS code exists but the note is too broad to identify the affected path.

Severity rubric: **P0** possible data loss/corruption or common-path wrong results; **P1** wrong results on narrow preconditions, server crash, or stack overflow; **P2** bounded leaks, edge panic, hang with workaround, or major performance regression; **P3** messages, catalog noise, telemetry/console, metrics, timeouts, or operational guidance.
